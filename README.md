# TARANG RF Tags — Smart Item Finder

Digital interactive manual and product showcase for TARANG RF Tags by Krioj Technologies.

## Tech Stack

- React + Vite
- Tailwind CSS v4
- motion/react
- qr-code-styling

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
